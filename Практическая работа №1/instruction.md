# Создание локального и удалённого репозитория. Клонирование

## Создание локального репозитория

1. В GitHub Desktop нажмите **Создать новый репозиторий на вашем
   локальном диске**.
2. Присвойте репозиторию имя `learning-git`.
3. Выберите **Инициализировать этот репозиторий с помощью README**,
   чтобы автоматически создать пустой файл `README.md`.
4. Щёлкните **Создать репозиторий**.

## Создание удалённого репозитория

1. В GitHub Desktop нажмите **Опубликовать репозиторий**.
2. Во всплывающем окне нажмите **Опубликовать репозиторий** ещё раз.
3. Чтобы увидеть удалённый репозиторий, нажмите **View on GitHub**.

## Клонирование репозитория

1. На GitHub перейдите на главную страницу репозитория.
2. Над списком файлов щёлкните **Code**.
3. Скопируйте URL-адрес репозитория:
   - для HTTPS выберите вкладку **HTTPS** и нажмите значок копирования;
   - для SSH выберите вкладку **SSH** и нажмите значок копирования.
4. Откройте Git Bash.
5. Измените текущий рабочий каталог на расположение, где должен
   находиться клонированный каталог.
6. Введите `git clone` и вставьте URL-адрес:
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
7. Нажмите **Enter**, чтобы создать локальный клон.

Пример вывода:
    $ git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
    > Cloning into `Spoon-Knife`...
    > remote: Counting objects: 10, done.
    > remote: Compressing objects: 100% (8/8), done.
    > remote: Total 10 (delta 1), reused 10 (delta 1)
    > Unpacking objects: 100% (10/10), done.
